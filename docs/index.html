1. 动机：天下没有免费的午餐

这个项目的起点不是“调一个加速脚本”，而是把两条看似独立的技术线索放到一起思考后的直接反馈：一条是 NVIDIA 关于混合线性注意力与状态分解的论文思路（SEED / GatedDeltaNet），另一条是苏剑林关于 Muon 优化器与矩阵谱结构的技术博客。

它们共同指向同一个底层规律——天下没有免费的午餐：

  • 线性注意力的代价（状态基与 Rank-1 Sink）：用 GatedDeltaNet 这类线性递推状态替代 $O(N)$ KV Cache 省下了显存，但递推状态会自动长出一个巨大的近似常数锚点（Rank-1 State Sink $b$）。在我们的 Qwen3.5-4B 实测中，这个 Rank-1 分量独占了 80.5%–84.0% 的状态能量；即使直接把测试轨迹里的 $b$ 替换成训练集均值（Replace_Sink_Mean），输出 KL 散度也仅变动 0.0012（Top-1 = 99.0%）。
  • “写比读容易”（Prefill vs Decode 不对称性）：读（Decode 阶段做深层推理）必须逐层穿过全部 32 层非线性网络；而写（Prefill 阶段把上下文写入记忆）理论上主要是增量写入新信息，是否意味着深层只需写而不必全深度计算？
  • 从 Muon 白化到“冻结偏置 $b$，解放 $ax$ 的秩”：苏剑林强调 Muon 优化器的关键是正交白化（Whitening）——把梯度矩阵的奇异值拉平，避免主特征方向吞噬所有更新、让小特征值也能参与训练。但从结构机理看，如果在状态或表达空间里 80%+ 能量天生被一个几乎不动的偏置 $b$ 占满，靠优化器白化只是治标；把偏置 $b$ 显式剥离并冻结，让剩余的秩专心表达动态上下文增量 $ax$，才更接近治本。
$$S_t = \underbrace{\hat{v} a_t^\top}_{b\text{（Rank-1 Sink，占 80\%+ 能量）}} + \underbrace{P_\perp S_t}_{ax\text{（正交动态内容）}}, \quad P_\perp = I - \hat{v}\hat{v}^\top$$ $$\text{Delta-Rule 精确解耦：}\quad ax_t = ax_{t-1}(\alpha_t I - \beta_t k_t k_t^\top) + \beta_t (P_\perp v_t) k_t^\top$$

这个直觉极其优雅。但真正做研究最怕“爱上自己的假说”——于是我们决定先打探针、做 SVD 和因果归因，把模型内部到底发生了什么照清楚，再决定怎么动手。结果，真实数据连续给了我们三次反转。

2. 反转一：探针救了方向二——浅层 Prefill 的真正瓶颈不在 GDN

按照最初的直觉，16 层浅层 Prefill（Uniform_k16）在长 SWE 轨迹上掉点严重（KL = 0.7292, Top-1 = 82.6%），我们理所当然地以为：只要冻结深层 12 层 GDN 的偏置 $b$、训练动态分量 $ax$，就能把 `KL` 救回来。

🔥 探针反转：98.8% 的掉点来自 4 层 Full-Attention KV，而不是 12 层 GDN 在 Uniform_k16 上做外科手术式缓存替换（Oracle 因果归因）： 即使给模型一个“上帝视角”完美恢复全部 12 层深层 GDN 状态（Oracle_GDN_Only），KL 也只从 0.7292 降到 0.6342（Top-1 = 84.4%）； 但反过来——12 层深层 GDN 全部原封不动留在浅层，只恢复那 4 层深层 Full-Attention 的 KV Cache（L19, L23, L27, L31）（Oracle_AttnKV_Only），KL 瞬间暴降 83×：从 0.7292 → 0.0088（Top-1 = 98.9%, Top-5 = 100.0%）！

紧接着的全 32 层预训练权重 SVD 与状态误差 SVD 彻底解释了背后的几何真相：

  • 4 层深层 Full-Attention 是全模型权重有效秩最低的层：W_K 有效秩从浅层 555.1 收缩到深层 394.8（r90 = 384 / 1024），W_V 收缩到 569.1；而深层 12 层 GDN 的 W_V 有效秩高达 1626.2（单头 113.9 / 128，非常满秩）。
  • GDN 的 Rank-1 Sink 是激活递推累积模式，而非权重低秩塌缩：经验 Sink 方向 $\hat{v}$ 与 W_V 前 4 主奇异子空间重合高达 42.5%–47.2%（随机仅 3.1%），但从 W_V 投影去掉 $\hat{v}$ 后权重有效秩几乎不变（113.9 → 113.7），且 W_out 对 $\hat{v}$ 反而有约 3× 衰减（gain = 0.287–0.360）。
  • 序列累积后的 GDN 状态误差 $E_{ax}$ 确实极低秩：有效秩仅 9.2（r90 = 10.4），因此当 4 层 Attn KV 修好后，叠加 MeanSink_b + Rank-8 ax 能把剩余 KL 再砍 4×（0.0088 → 0.0023, Top-1 = 99.8%）。

顺着探针指出的方向，我们只在 48 条训练轨迹（122,880 tokens）上用单次共享 Gram Cholesky 闭式求解（仅耗时 14.19s，零 SGD）对齐了这 4 层深层 Attn KV（U16_AttnKV_FullRidge）：在 零额外延迟（30.35s vs 30.32s，1.61× 真实 M5 Prefill 加速）下将 Uniform_k16 的 KL 压降 10.9×（0.7292 → 0.0667，Top-1 = 96.6%，Top-5 = 100.0%），速度和精度双杀 24 层的 Uniform_k24_Raw（1.21× / KL = 0.1035）。

4. 反转三：Decode 端的硬件现实与“反直觉的校准陷阱”

把视角切到 Decode 端：用 Layer-8 闭式 Ridge 旋转矩阵 $W_8$ 做自投机解码，离线模拟加速比高达 2.47×，但一落到 M5 真实闭环立刻跌成 1.49×。拆解墙钟耗时后发现两大元凶：

  1. 庞大的 LM_head 吞掉了 45.9% 的解码时间：Qwen3.5 的 tied 词表头高达 248,320 × 2,560 ≈ 0.64B（占 4B 模型的 16%），每打一步草稿都要乘全量词表（单步 5.58–6.78 ms）。
  2. 长思考阶段与浅层草稿错配：在 Row 16 这种 90-token 推理上，L8 空跑 117 步无效草稿，把速度拖垮到 1.15×–1.22×。

查看 MLX 底层张量后我们捡到一个巨大的硬件红利：QuantizedEmbedding（bits=8, group_size=64）是沿隐藏维 D=2560 逐行独立量化的！这意味着按 Top-8K (训练集) ∪ unique(prompt_ids) 切片子矩阵并跑 mx.quantized_matmul，结果与全词表逐位完全一致（max_abs_diff = 0.0），单步 LM_head 直接提速 11.5×–22.6×（5.575 ms → 0.484 ms）。

⚡ 踩坑与反转：为什么最简单的“不加 logZ 校准”反而最快？ 最初我们担心剪成 8K 词表会导致 OOV 假高置信度，于是训练了闭式 Ridge logZ 校准器，结果踩出两个极具启发性的发现：
1. 嵌套拟合范数漂移：把上游 in-sample 拟合出来的 W_8 输出喂给下游 logZ 回归器时，内部验证 R²=0.937，测试集却因 ||rotated_h|| 样本外膨胀（145.24 → 150.93）雪崩到 R²=0.3386, bias=+1.57；改用冻结原生的 normed_h8 后立刻恢复到 R²=0.8011, bias=+0.35。
2. 非对称代价碾压理论完美：8K 动态词表在未见测试集上覆盖率已达 99.43%（OOV 假高置信度仅占全部 token 的 0.28%，4/1413），而即便 R²=0.80 的线性预测器也会误杀 8.8%–33.6% 的词表内高置信度草稿。因此 PhaseGate_SL8K_NoCal（不加校准）以 1.86×（44.63 tok/s，6/6 贪婪完全一致，单条最高 2.41×）夺冠！

5. 终局闭环：把 Prefill (1.94×) 与 Decode (1.89×) 拼成 1.93× 端到端管线

在真实 1.6K–6.1K 长上下文 Coding Agent 任务中，Prefill 占了总推理耗时的 78%（60.79s / 77.86s）。这就是为什么只做 Decode 加速（哪怕 Decode 本身快了 2.02×），端到端总提速也只有 1.14×；只做 Prefill 加速只有 1.58×——必须把 Prefill 与 Decode 拼成一条管线，才能拿到乘性收益。

6. 边界、反思与“冻结 $b$ 解放 $ax$”的真正战场

回头看最初从 NVIDIA SEED 与苏剑林 Muon 白化出发的直觉，这轮完整实验给了我们三个非常清醒、诚实的结论：

✅ 哪些直觉被验证了，哪些被数据修正了？
  • 写比读容易 & 信息稀释（强证实）：旧工具输出几乎不需要深层 Prefill（Skip_OldTool_k16 零训练 99.8% Top-1），而思考与工具调用在 Decode 端也完全属于两种算力负载。
  • 混合架构浅层 Prefill 的主要矛盾（关键修正）：在 Qwen3.5-4B（3:1 GDN/Attn 混合架构）中，浅层 Prefill 的痛点在 4 层深层 Full-Attention KV（占 98.8% KL 损失且权重秩最低），而不是 12 层 GDN。
  • “冻结偏置 $b$、解放 $ax$ 的秩”的真正战场：为什么它在我们的 token 级线性 Prefill 对齐上没有拉开差距？因为 token 级单头 v_t 本身是满秩的（113.9/128，Rank-16 仅保留 56.3% 能量），而真正呈现极低秩（effRank = 9.2）的是跨长序列累积后的递推状态 $ax$。因此“冻结 $b$ 训 $ax$”的主战场不在浅层 Prefill 的单步线性投影，而在超长上下文 GDN 状态压缩与 Post-training 阶段对状态表达秩的释放。
